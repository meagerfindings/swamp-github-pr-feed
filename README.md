# swamp-github-pr-feed

[swamp](https://swamp.club) extension `@mgreten/github-pr-feed` — poll open
GitHub PRs for new reviews, comments, and check failures with watermark-based
deduplication and rate-limit backoff.

Extension documentation: [extensions/models/README.md](extensions/models/README.md)

Install: `swamp extension pull @mgreten/github-pr-feed`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
